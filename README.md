Windows PC Recovery Tool (PRT) is a personal open-source project developed by **Roid.wim**. It aims to provide a simple, lightweight command-line toolkit for Windows recovery, troubleshooting, and system maintenance.

## Planned Features

* Restart Windows
* Shut down Windows
* Boot into Windows Recovery Environment (WinRE)
* Display system information
* Disk and storage tools
* Network information
* Windows utilities
* Additional recovery and troubleshooting tools
* Disk Utilities

## Current Status

The project is currently being rewritten from scratch and is still in active development. Features, commands, and the overall structure may change before the first public release.

## Requirements

* Windows 7 / 8.1 / 10 / 11 (Still Testing Windows XP / Vista )
* Command Prompt (Administrator privileges Highly recommended)
